使用你自己的 API Key

Bring your own API keys

Key 只保存在当前 Chrome 配置中。DeepSeek Key 用于 AI 功能；可选的 Supadata Key 仅在无法直接获取 YouTube 字幕时使用。本扩展没有开发者服务器，也不收集分析数据。

Keys stay in this Chrome profile. A DeepSeek key enables AI features; an optional Supadata key is used only when direct YouTube subtitle retrieval fails. This extension has no developer server or analytics.

字幕备用服务 Transcript fallback

TranslatorX 会优先直接读取人工字幕和自动字幕。只有直接读取失败时，才会使用这个 Key。 创建 Supadata 账号并获取 Key。Supadata 会在注册引导过程中生成 Key。

TranslatorX reads manual and automatic subtitles directly first. This key is contacted only if direct retrieval fails. Create a Supadata account and key. Supadata generates the key during onboarding.
